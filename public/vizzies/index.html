VJ VIZZIES SUITE

The show laptop package: the VJ VIZZIES clip + fractal player (grandMA3 sACN / OSC, full screen over HDMI, NDI previs) plus the OATS NDI HUB camera suite (multiview, free PTZ, webcams as NDI cameras, tally), in one double-click installer.

What it does

  • VJ VIZZIES: fractal + clip player at the display rate, output window on the HDMI show display; sACN universe + OSC from grandMA3; browser controls at http://<the Mac>:8090 from the lighting network; NDI previs 'OATS VIZ Program'; a Mac app with a menu-bar health dot (start / stop / restart, logs, open at login); a Windows launcher for the PC.
  • OATS NDI HUB: every NDI source in a browser multiview with click-to-select tally, joystick / zoom / presets / autofocus for any NDI PTZ camera; an Insta360 Link 2, an OBSBOT or any UVC webcam as an NDI camera WITH PTZ and a protected mic (one sender per camera); a display as NDI; tally on a phone page, the OBSBOT LED or a lighting console; OSC input on 7081.
  • Installs to ~/Applications (VJ VIZZIES, OATS NDI HUB) with login items; run the installer again to update, your settings, scenes and media are kept. Each Mac gets its own NDI machine name, so a laptop and the show Mac coexist on one network.

You need

  • A Mac with macOS 14 or later: Apple Silicon or Intel (the 2020 MacBook Pro is a supported target); universal binaries, nothing to compile. The fractal governor lowers the internal resolution on a weaker GPU to hold the frame rate.
  • The NDI runtime: NDI Tools (free, ndi.video/tools) installs it, and the installer carries a copy for Macs where Tools left it out.
  • Apple Silicon only: Rosetta 2 (one Terminal command, in the read-me).

Install

unzip, then double-click  INSTALL.command
(right-click › Open › Open if macOS refuses the first time)

it asks for this Mac's NDI machine name and the lighting network interface, once,
installs both parts and starts them. Then, from the same Terminal window, once:
"~/Applications/OATS NDI HUB/oats-cam/cam.sh" restart
and click Allow: camera and microphone permission belong to the app that starts the sender.
