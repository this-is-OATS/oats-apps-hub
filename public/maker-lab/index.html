MAKER-LAB

The embroidery bench for a Brother PE-770: build stitch files (satin lettering in the Mac's own fonts, fills, borders, pictures), see them as design, stitches and real thread, check them against the machine's rules, and load the USB stick. One Mac app; it updates itself.

⬇ Download for Mac (.dmg, 113 MB)v1.1.0 · 2026-11-08 · Apple Silicon, macOS 13 or later

Install

  1. Download the .dmg and open it.
  2. Drag MAKER-LAB to the Applications folder next to it.
  3. Open MAKER-LAB from Applications. The first time, macOS says it cannot verify the app (it is not notarized). Open System Settings › Privacy & Security, scroll down to the line about MAKER-LAB, click Open Anyway, then Open. (macOS 14 and earlier: right-click the app, Open, Open.) If it says the app is damaged, run xattr -d com.apple.quarantine "/Applications/MAKER-LAB.app" in Terminal.
  4. If macOS asks about removable volumes (the stick), click Allow.
  5. Done. From then on the app looks for a newer version when it opens and every 45 minutes, downloads it in the background, and installs it once the Mac has been idle for ten minutes and nothing is building or copying. MAKER-LAB › Check for Updates… does it now.

What it does

  • Builds .pes stitch files for the PE-770 from words, a font and a shape: satin or fill lettering, raised letters, borders, pictures; every file passes the machine checks before it can go on the stick.
  • Shows each file three ways, plays the sew-out, lists every thread stop, and loads the stick (a button, never by itself).
  • Keeps everything it makes in ~/Library/Application Support/MAKER-LAB; an update never touches it.

You need

  • An Apple Silicon Mac with macOS 13 or later.
  • A USB stick named EMBROIDER (FAT32) to load files for a PE-770.
  • Optional: the claude command line tool for the chat bar.

Release notes

First version that installs from a disk image and updates itself. Letters made of A K M N T V W X Y in an outline font are sewn as clean rows in place of the satin that piled up at their junctions. Padded, raised and domed letters sew the padding of every letter first and the covering stitches after it. The Real thread view draws thread in the order it is sewn, so padding no longer shows through the top, and every page shows the app's version.
